# MicMod

Windows向けリアルタイムノイズ除去アプリ

## ダウンロード

`MicMod Setup 0.1.0.exe` をダウンロードして実行してください。

## 機能

- 🎤 RNNoiseベースのAIノイズ除去
- 🔊 エコーキャンセル（Browser / WASAPI）
- 🎵 ピッチ / フォルマント変換
- 🎛️ イコライザー・コンプレッサー
- ✨ エキサイター・ノイズゲート

## 動作環境

- Windows 10/11 (64-bit)

## Web版

ブラウザでも利用できます（Chrome/Edge推奨）

https://micmod.app
